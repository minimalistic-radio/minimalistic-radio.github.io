# minimalistic-radio.github.io

The website of [Minimalistic Radio](https://github.com/zal3wa/minimalistic-radio), a tiny tray radio for Windows, macOS and Linux:
the landing page, and the page behind shared station links (`https://minimalistic-radio.github.io/#n=…&u=…`, the part after `#` never reaches a server).
One static `index.html`, served by GitHub Pages, with no build step, no outside scripts or fonts, no analytics and no cookies. The app pictures come from the main repository's `docs/screenshots` (raw.githubusercontent.com), so they are always the current ones.
