# minimalistic-radio.github.io

The page behind shared station links of [Minimalistic Radio](https://github.com/zal3wa/minimalistic-radio), a tiny tray radio for Windows, macOS and Linux.
A link like `https://minimalistic-radio.github.io/#n=…&u=…` shows the station and opens it in the radio; the part after `#` never reaches a server.
One static `index.html`, served by GitHub Pages, with no build step, no outside scripts, no analytics and no cookies.
